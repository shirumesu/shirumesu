这次改了什么
  1. 深色模式：每张图都有一份单独的深色版本，README 通过 <picture> 跟随 GitHub 主题自动切换。用上方的「GitHub 深色」可以直接看效果。
  2. 深色怎么换的：墨色和纸色互换，纸色变成深海夜色 #0F1A20。海蓝提亮到 #6CC6DC。白色高光改成暗玻璃色。荧光笔的黄降到约一半浓度，免得刺眼。
  3. 落在黄色上的字：便签和按钮上的字两种模式都保持深色，深色模式下便签也更实一点，保证看得清。
  4. 访客计数器：worker 支持 ?theme=dark，README 在深色模式下请求这个地址。两个地址都会计数，但每次访问只会加载其中一个。
